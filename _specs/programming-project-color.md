# プログラミングプロジェクトの色の修正

## 目的

ダッシュボードの「最近のプロジェクト」で、プログラミングプロジェクトのカード左側の線の色が本来の色（`rgba(0, 0, 140, 0.6)`）より薄く表示されている。本来の色で表示されるようにする。

### 調査結果

- カード左側の線は `--project-color` で描いており、その値は API が返すプロジェクトの `color` をそのまま使っている。フロントエンドで色を変えている箇所はない。
- API の初期データ（`app/api/datastore/index.ts`）では、プログラミングの `color` が `#00008c60` になっている。8 桁の 16 進数の末尾 `60` は不透明度 0x60 = 96/255 ≒ 0.38 を表すため、実際の表示は `rgba(0, 0, 140, 0.38)` 相当になる。
- 本来の `rgba(0, 0, 140, 0.6)` は `#00008c99` にあたる。英語（`#0019ff99`）・プライベート（`#00a5ff99`）はいずれも末尾が `99`（0.6）で、プログラミングだけが `60` になっている。「60%」のつもりで `60` と書いた誤りと考えられる。
- `app/api/` は改変禁止だが、初期データの誤りのため、例外として `app/api/datastore/index.ts` のプログラミングの `color` を直す。プロジェクトの色を変更する API（`PATCH` など）はないため、ほかに直す手段はない。教材の配布元にも報告する。
- 同じ `project.color` はダッシュボード以外でも使われているため、初期データを直せばすべての画面に反映される。

## 対象ページ

- `/`（ダッシュボードの「最近のプロジェクト」）
- `/projects`（プロジェクトカード）
- `/projects/programming`（プロジェクト詳細カード）
- サイドバーのプロジェクト一覧（全ページ共通）

## 要件

- [ ] API の初期データで、プログラミングプロジェクトの `color` が `#00008c99`（= `rgba(0, 0, 140, 0.6)`）になる。`app/api/` の変更はこの 1 行だけにする。
- [ ] ダッシュボードの「最近のプロジェクト」で、プログラミングのカード左側の線が `rgba(0, 0, 140, 0.6)` で表示される。
- [ ] `/projects` のプログラミングのカード左側の線が `rgba(0, 0, 140, 0.6)` で表示される。
- [ ] `/projects/programming` のプロジェクト詳細カード左側の線が `rgba(0, 0, 140, 0.6)` で表示される。
- [ ] サイドバーのプログラミングの丸印が `rgba(0, 0, 140, 0.6)` で表示される。
- [ ] 英語・プライベートの色は変わらない。
- [ ] `CLAUDE.md` と `docs/architecture.md` の、`app/api/` を改変しないという記述に、この初期データの修正だけは例外であることを書き足す。

## 対象外

- `app/api/` の、プログラミングの `color` 以外の改変
- フロントエンドで色を読み替える処理の追加
- 配布元への報告そのもの（PR とは別に人が行う）
- プロジェクトの色を編集する機能
- 英語・プライベートなど、他のプロジェクトの色の見直し
- 線の太さ・角丸など、色以外の見た目の変更

## 使う API・データ

- `GET /api/v1/users/projects` の各プロジェクトの `color`（`ProjectsProvider` の `useProjects()` 経由で取得済み）

## デザイン・補足

- 本来の色: `border-left: 5px solid rgba(0, 0, 140, 0.6);`（= `#00008c99`）
- 線は `src/_pages/home/ui/RecentProject.module.scss` の `border-left: 5px solid var(--project-color, ...)` で描いている。
