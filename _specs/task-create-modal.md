# タスク追加モーダル

## 目的

どのページからでも、ヘッダーのボタンからタスク追加モーダルを開けるようにする。このプロジェクトは API から取得した情報を表示する課題のため、今回は見た目と入力フォームの動きだけを作り、タスクの作成（API への送信）はしない。

## 対象ページ

- `/`（ヘッダーは全ページ共通。PR のスクリーンショットはトップでヘッダーのボタンを押した状態を撮る）

## 要件

- [ ] ヘッダーの「タスクを追加」ボタン（`+` アイコン、`aria-label="タスクを追加"`）を押すと、モーダルが開く
- [ ] モーダルは画面中央に白い面で表示され、背面は暗いオーバーレイで覆われる
- [ ] 右上に閉じるボタン（`X` アイコン、`aria-label="閉じる"`）がある。押すとモーダルが閉じる
- [ ] 見出し「タスクを追加」が左上に表示される
- [ ] フォームの項目が上から次の順で縦に並ぶ（ラベルは小さめの文字）
  - [ ] 「プロジェクト」（必須。ラベルの後ろに赤系の `*`）: セレクトボックス。先頭は「プロジェクトを選択してください」（選択不可のプレースホルダー）で、以降は `useProjects()` のプロジェクト名が並ぶ
  - [ ] 「タスク」（必須。`*` 付き）: 1 行のテキスト入力。プレースホルダーは「タスクを入力。 例）英会話レッスンの予約、React公式ドキュメントを1ページ読む」
  - [ ] 「説明・メモ」: 複数行のテキスト入力（`textarea`）。プレースホルダーは「タスクの説明・メモ」
  - [ ] 「締切日」（必須。`*` 付き）: 日付入力（`type="date"`）。初期値は今日の日付
  - [ ] 「ステータス」: セレクトボックス。選択肢は「未完了」（`scheduled`）・「完了」（`completed`）・「アーカイブ」（`archived`）。初期値は「未完了」
- [ ] 下部に「作成」ボタン（緑、`--color-primary`）と「キャンセル」ボタン（濃紺）が横に同じ幅で並ぶ
- [ ] 「キャンセル」を押すとモーダルが閉じる。Esc キーを押す、オーバーレイ（モーダルの外側）をクリックしても閉じる
- [ ] プロジェクト・タスク・締切日のどれかが未入力のとき、「作成」を押してもモーダルは閉じず、未入力の項目にその旨のエラーが表示される（タスクは前後の空白だけの入力も未入力とみなす）
- [ ] すべて入力して「作成」を押すと、モーダルが閉じる（API には送らない）
- [ ] モーダルを開き直したとき、前回の入力内容は残っていない（初期値に戻る）
- [ ] モーダルが開いている間、背面のページはスクロールしない。モーダルの内容が画面に収まらないときは、モーダルの中でスクロールできる
- [ ] モーダルを開くと最初の入力欄（プロジェクト）にフォーカスが移り、閉じるとヘッダーのボタンにフォーカスが戻る。`role="dialog"`・`aria-modal="true"`・見出しとの `aria-labelledby` を付ける
- [ ] デスクトップ表示で崩れない

## 対象外

- タスクの作成（`POST /api/v1/users/tasks` への送信）、作成したタスクの一覧・件数への反映、送信中・送信失敗の表示
- タスクの編集・削除、マイルストーン（`kind: "milestone"`）の作成、親タスクの指定
- 開始日（`startingAt`）の入力
- 「プロジェクト」セレクトボックスからの新規プロジェクト作成
- 作成成功のトースト表示
- モバイル表示への対応、ダークモード

## 使う API・データ

- API は呼ばない。プロジェクト一覧は既存の `useProjects()`（`entities/project`）を使う。

## デザイン・補足

- 参考画像: 添付のスクリーンショット（モーダルは画面の大部分を占める大きな白い面。内側のフォームは中央の幅 640px 前後に収める）
- 見出し「タスクを追加」は小さめ・薄い色の文字（`--color-text-sub`）。右上の `X` は `lucide-react` の `X`
- 入力欄は白地に薄い枠・淡い影（`--color-border`、`--shadow-card`）、角丸。セレクトボックスは右端に `ChevronDown` 風の矢印
- 「作成」ボタンは緑地（`--color-primary`）に白い太字、「キャンセル」ボタンは濃紺地に白い太字で、どちらも角丸・影つき。濃紺に当たる CSS 変数は `globals.scss` にない（追加するか、既存の変数で代用できないか実装時に確認する）
- 必須マークの `*` の赤系に当たる CSS 変数は `globals.scss` にない（同上）
- ボタンの起点: `src/_app/layouts/Header.tsx` の `ACTIONS` の「タスクを追加」（現状は動作が未実装）。モーダルはヘッダーから開くため `_app/layouts` 側で状態を持つ。モーダルの枠は他でも使える `shared/ui` の部品にしてもよい
- 同じ形のフォームは `feature/task-detail`（PR #6）の `TaskDetailForm` にあるが、未マージのためコードは流用しない
