# ヘッダーのタスク検索

## 目的

ヘッダーには「タスクタイトルで検索」の検索欄があるが、見た目だけで、文字を入力しても何も起きない（`src/_app/layouts/Header.tsx`）。この検索欄に入力すると、タイトルが当てはまるタスクが検索欄の下に一覧で表示され、そこからタスク詳細を開けるようにする。

## 対象ページ

- 全ページ（ヘッダーの検索欄）。スクリーンショットは `/` で撮る。

## 要件

### 検索欄

- [ ] 検索欄に文字を入力するたびに、検索欄のすぐ下に検索結果の一覧（ドロップダウン）が表示され、入力に合わせて内容が変わる。Enter を押す必要はない。
- [ ] 入力の前後の空白は無視する。空（空白だけ）のときは、検索結果の一覧を表示しない。
- [ ] Enter を押しても、ページは移動せず何も起きない。
- [ ] 文字が入っているあいだ、検索欄の右端に「×」のボタンが表示される。押すと入力が空になり、検索結果の一覧が閉じる。
- [ ] Esc キーを押すか、検索欄と検索結果の一覧の外をクリックすると、検索結果の一覧が閉じる。入力した文字は残り、検索欄に戻ってフォーカスすると再び表示される。

### 検索の対象

- [ ] タイトルにキーワードを含むタスクが表示される（部分一致）。
- [ ] 英字の大文字・小文字、全角・半角（英数字・カタカナ）は区別しない（例: 「ﾀｽｸ」でも「タスク 1」が、「１」でも「タスク 1」が当てはまる）。
- [ ] 「未完了」だけでなく、「完了」「アーカイブ」のタスクも含めて、すべてのタスクを検索する。
- [ ] タスク追加モーダルで作成したタスクや、各ページで変更したタスクも、次に検索したときの結果に反映される。

### 検索結果の一覧

- [ ] 一覧の各行には、1 行目にタスクのタイトル、2 行目の左にプロジェクト名、右に期限日（「2026/11/11」の形）が表示される。
- [ ] 行を押すと、そのタスクの詳細（`/tasks/<タスクの id>`）に移動し、検索結果の一覧は閉じる。
- [ ] 行は Tab キーでも順に移動でき、Enter で開ける。
- [ ] 一覧には、当てはまるタスクのうち最大 10 件だけが表示される。11 件目以降は表示せず、一覧の中もスクロールしない。
- [ ] 一覧は期限が近い順（期限日の昇順）に並ぶ。ダッシュボードと `/tasks` のタスク一覧と同じ順で、10 件は期限の近いものから選ばれる。
- [ ] 当てはまるタスクがないときは、一覧に「一致するタスクはありません」と表示される。
- [ ] タスクの取得中は「読み込み中…」、取得に失敗したときは「読み込みに失敗しました」と一覧に表示される（ほかの一覧と同じ文言）。

## 対象外

- 検索結果を表示する専用のページ（`/tasks` での絞り込みなど）
- Enter での検索・ページ移動
- 矢印キーでの行の選択
- タスクのタイトル以外（説明・プロジェクト名など）での検索、プロジェクトの検索
- 検索履歴、キーワードの強調表示
- 11 件目以降の表示（一覧内のスクロール、「ほか N 件」の表示、もっと見るリンク）
- 並び順の切り替え
- 検索結果の一覧からのタスクの編集・削除
- ヘッダーのヘルプ・通知の実装
- API（`app/api/`）の変更

## 使う API・データ

- `GET /api/v1/users/tasks`（仕様は `/api/v1/spec` を参照）
  - クエリは `limit`・`page`・`status` だけで、**キーワードで絞り込むパラメーターはない**（`app/api/v1/users/tasks/route.js`）。`app/api/` は改変できないため、タイトルでの絞り込みはクライアント側で行う。
  - `status` を指定しないと `scheduled` のタスクだけが返る。`route.js` は `searchParams.get("status")` の 1 つの値に対して `status.includes(it.status)` で判定するため、`status[]=…` のような配列の形（axios の既定の送り方）では指定が無視され、`scheduled` だけになる。今の `GetTasksParams.status`（`src/shared/api/task.ts`）は 1 つのステータスしか受け付けない。
  - 結果は期限（`deadline`）の昇順で、`limit` で区切られる（初期値 20）。レスポンスの `pageInfo.totalCount` で全件数が分かる。
  - 初期データのタスクは 100 件で、タイトルは「タスク 1」〜「タスク 100」、プロジェクトはすべて「プログラミング」。
- タスクの `project.name` をプロジェクト名、`deadline` を期限日に使う。期限日の表示は `@/shared/lib` の `toDisplay()`（「2026/10/28」の形）が使える。
- タスクが作成・変更されたことは、`useTaskChanges()` の `revision` で分かる。

## デザイン・補足

- 添付のスクリーンショットの見た目にする。
  - 検索欄は今の `<input>`（`placeholder` と `aria-label` は「タスクタイトルで検索」、左に虫眼鏡のアイコン）をそのまま使い、右端に「×」のアイコンボタンを足す。「×」は濃い色（`--color-navy` 相当）。
  - 検索結果の一覧は、検索欄と同じ幅で、すぐ下に重ねて表示する白いパネル（`--color-surface`）。角丸で、影は `--shadow-card` か `--shadow-modal`（スクリーンショットは薄めの影）。ページの他の要素より手前に出す。
  - 各行は、上にタイトル（本文の大きさ、`--color-text-sub` 相当の文字色）、下の左にプロジェクト名、右に期限日（どちらも小さめで `--color-text-muted` 相当の文字色）。行のあいだに区切り線はなく、上下の余白で区切る。
  - 行にマウスを乗せたときの背景は、既存のホバー色（`--color-primary-bg`）に揃える。
- 検索欄は `src/_app/layouts/Header.tsx` と `Header.module.scss` にある。
