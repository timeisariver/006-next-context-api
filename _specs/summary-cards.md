# 進捗サマリーの集計カード改善

## 目的

ダッシュボードの「進捗サマリー」下段にある「完了タスク」「予定タスク」「完了率」の 3 枚の集計カードの表記を、参考画像に合わせて見直す。数値の横に前週比を添え、完了率はドーナツグラフの中に数値を出すことで、今週の進み具合と前の週からの変化を一目で読み取れるようにする。

## 対象ページ

- `/`（ダッシュボード）

## 要件

### 完了タスク・予定タスクのカード

- [ ] ラベル（「完了タスク」「予定タスク」）の下に、期間内の合計数を大きく表示する（現在と同じ値）。
- [ ] 合計数の右に、同じ行で前週比の増減率（例: `+44%`）を緑の太字で表示する。
- [ ] 増減率の右に、灰色の小さな文字で「前週比」と表示する。
- [ ] 合計数・増減率・「前週比」は下端（ベースライン）をそろえて横に並べる。

### 前週比の値と表記

- [ ] 前週比は API に前の週のデータがないため、参考画像と同じ固定のダミー値を表示する（完了タスク `+44%`、予定タスク `+36%`、完了率 `+8%`）。期間の選択ボタンと同じく、コード上で「見た目のみ」と分かるようにしておく。
- [ ] 増減率は整数のパーセントで、プラスは `+44%`（`--color-primary`）、マイナスは `-12%`（`--color-danger`）、0 は `±0%`（`--color-text-sub`）と表記する。
- [ ] 完了率の前週比は、完了率の差（ポイント）を `+8%` の形で表記する。

### 完了率のカード

- [ ] ラベル「完了率」の下に、ドーナツグラフを左に置き、その右に前週比の増減率（緑の太字）と「前週比」（灰色の小さな文字）を横に並べる。
- [ ] 完了率のパーセント（例: `0%`）は、ドーナツグラフの輪の中央に太字で表示する。輪の外に大きく表示していた完了率の数値はなくす。
- [ ] 完了率の求め方（完了タスクの合計 ÷（完了タスクの合計 + 予定タスクの合計）を四捨五入した整数、合計が 0 のときは 0%）と、ドーナツの塗り分けは今と同じにする。

### 共通

- [ ] 3 枚のカードの、ラベル・数値の位置と高さをそろえる。

## 対象外

- 棒グラフ・凡例・期間表示など、集計カード以外の進捗サマリーの変更。
- 期間（週・日・月・年）の切り替え。
- 前の週のデータを取得するための API の追加・変更（`app/api/` は改変しない）と、実データからの前週比の計算。
- 狭い画面（モバイル）向けのカードの並べ替え。今の 3 列のままにする（ダッシュボードにはまだメディアクエリがない）。
- 増減率のツールチップや、カードをクリックしての詳細表示。
- 他のダッシュボード部品（最近のプロジェクト、タスク一覧）の変更。
- ダークモード対応。

## 使う API・データ

- `GET /api/v1/users/stats`（仕様は `/api/v1/spec` を参照）。既存の `Summary` が `shared/api` の `getStats()` で取得済みのデータを使う。
  - レスポンスは `{ data: Stats[] }`。`Stats` は `{ label, type, data: { date, value }[] }` で、`type` は `completed`・`todo` の 2 系列。
  - 返すのは今日の前後 3 日の計 7 日分だけで、前の週のデータはない（値は起動のたびにランダム）。

## デザイン・補足

- 参考画像（ユーザーが添付したスクリーンショット）の構成:
  - 3 枚のカードを横に並べる。枠線付きの角丸、白地（今のカードと同じ）。
  - 左上にラベル（小さめ・太字・濃い灰色）。
  - 完了タスク・予定タスク: ラベルの下に、大きく細い数値 → 緑の太字の `+44%` → 灰色の「前週比」が 1 行に並ぶ。
  - 完了率: ラベルの下に、灰色の輪のドーナツ（中央に太字の `0%`）→ 緑の太字の `+8%` → 灰色の「前週比」が 1 行に並ぶ。
- 色は `src/_app/styles/globals.scss` の CSS 変数を使う。増減率の緑は `--color-primary`、「前週比」の灰色は `--color-text-sub` または `--color-text-muted`、ドーナツの地の灰色は今と同じ `--color-border` が当たる。
- 対象のコードは `src/_pages/home/ui/Summary.tsx`（カード）と `src/_pages/home/ui/CompletionDonut.tsx`（ドーナツ）。
- 以前の仕様書 `_specs/progress-summary.md` では、前週比は API にデータがないため対象外としていた。今回は見た目を参考画像に合わせるため、ダミー値で表示する。API が前の週のデータを返すようになったら、実データからの計算に置き換える。
