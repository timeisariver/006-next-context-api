# 表示幅の固定（viewport）

## 目的

このアプリはデスクトップ向けのレイアウトだけを持ち、メディアクエリによるレスポンシブ対応をしていない。そのため、画面の狭い端末で開いたり、ブラウザのウィンドウを狭めたりすると、サイドバーやヘッダー（検索欄の `min-width: 520px` など）がはみ出して崩れる。

レスポンシブ対応はしない前提で、表示幅を固定し、狭い画面でもデスクトップと同じレイアウトのまま見られるようにする。

- スマートフォン・タブレット: Next.js の既定の viewport（`width=device-width, initial-scale=1`）では端末の幅で描画される。`<meta name="viewport" content="width=1440">` で表示幅を固定し、デスクトップのレイアウトを縮小して表示する。
- デスクトップのブラウザ: viewport の指定は効かないため、ウィンドウを狭めたときはレイアウトの幅を保ったまま横スクロールできるようにする。

幅は、PR のスクリーンショット（`scripts/pr-screenshots.mjs`）で見た目を確かめている 1440px にそろえる。

## 対象ページ

すべてのページ（ルートレイアウトで設定するため）。

- `/`
- `/projects`
- `/projects/[slug]`
- `/tasks`
- `/tasks/[id]`

## 要件

- [ ] すべてのページの HTML の `<head>` に、`<meta name="viewport" content="width=1440">` が 1 つだけ出力される（Next.js の既定の `width=device-width, initial-scale=1` は出力されない）。
- [ ] スマートフォンの幅（例: 390px）で開くと、デスクトップと同じレイアウト（ヘッダー・サイドバー・本文が横に並んだ状態）が画面の幅に収まるよう縮小して表示され、横スクロールが出ない。
- [ ] スマートフォン・タブレットで、ピンチ操作による拡大ができる（拡大を禁止する指定をしない）。
- [ ] デスクトップのブラウザでウィンドウの幅を 1440px より狭めても、レイアウトは 1440px の幅を保ち、ページ全体を横スクロールして右端まで見られる（ヘッダーやサイドバーが切れたまま見えなくなることがない）。
- [ ] ウィンドウの幅が 1440px 以上のときは、変更前と同じく画面の幅いっぱいに広がり、横スクロールは出ない。
- [ ] サイドバー・本文が縦にスクロールする動きと、ヘッダーが上に固定されている見た目は変更前と変わらない。

## 対象外

- メディアクエリによるレスポンシブ対応（モバイル向けのレイアウトを作ること）。
- `themeColor` など、viewport の幅以外の項目の設定。
- ページごとに異なる viewport を設定すること。
- PR 用スクリーンショットの撮影幅の変更や、モバイル幅でのスクリーンショット。

## 使う API・データ

なし。

## デザイン・補足

- Next.js（App Router）では `<meta name="viewport">` を `<head>` に直接書かず、`viewport` オブジェクト（または `generateViewport`）を `layout.tsx` からエクスポートして設定する（`node_modules/next/dist/docs/01-app/03-api-reference/04-functions/generate-viewport.md`）。Server Component でのみ使える。
- 今のルートレイアウトは `body` を `height: 100dvh; overflow: hidden` にして、サイドバーと本文の中だけをスクロールさせている（`src/_app/layouts/RootLayout.module.scss`）。横スクロールを足すときに、この縦スクロールの動きを壊さないこと。
- スマートフォンの確認は、ブラウザの開発者ツールのデバイスモード（例: iPhone 14、390px）で行える。
