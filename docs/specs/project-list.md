# プロジェクト一覧ページ

## 目的

ダッシュボードには直近 3 件のプロジェクトしか出ないため、すべてのプロジェクトを 1 画面で見渡せるようにする。ダッシュボードの「すべてのプロジェクトをみる」リンクの遷移先になる。

## 対象ページ

- `/projects`

## 要件

- [ ] `/projects` にアクセスすると、プロジェクト一覧ページが表示される
- [ ] ページ見出し（`h1`）に「プロジェクト」と表示される
- [ ] 全プロジェクトがカードで 1 列に縦並びで表示される（`ProjectsProvider` の `useProjects()` の値を使い、API が返す順のまま並べる）
- [ ] 一覧の上に「1 / 1 (3 件)」の形式で、現在のページ / 全ページ数と総件数が表示される
- [ ] 各カードに、プロジェクト名（プロジェクトの色）、期限日（カレンダーアイコン付き・`YYYY/MM/DD`）、ゴール（`goal`、太字の大きめの文字）、あるべき姿（`shouldbe`、薄い色の文字）、マイルストーン数、タスク数（右下）が表示される
- [ ] 各カードの左端にプロジェクトの色（`color`）の太い縦線が表示される
- [ ] 各カードをクリックすると `/projects/<slug>` に遷移する
- [ ] 1 ページに 10 件まで表示し、一覧の下（右寄せ）に「前へ」「ページ番号」「次へ」のページ送りが表示される。現在のページ番号は強調され、最初のページでは「前へ」、最後のページでは「次へ」が押せない
- [ ] 表示中のページは URL のクエリ（`?page=2`）で表され、直接開いても同じページが表示される。範囲外や不正な値のときは 1 ページ目として扱う
- [ ] ページ送りは、取得済みの全件（`useProjects()`）をブラウザ側で分けて表示する（API を `page` 付きで再取得しない）
- [ ] プロジェクトが 0 件のときは「プロジェクトがありません」と表示される
- [ ] データ取得中は「読み込み中…」、取得に失敗したときはエラーメッセージが表示される
- [ ] ダッシュボードの「すべてのプロジェクトをみる」から `/projects` に遷移できる
- [ ] デスクトップ表示で崩れない

## 対象外

- プロジェクトの追加・編集・削除
- プロジェクト詳細ページ（`/projects/<slug>`）の作成
- 検索・絞り込み・並べ替え・表示件数の切り替え
- 完了・予定・アーカイブなどの進捗（`stats.states`）の表示
- モバイル表示への対応

## 使う API・データ

- `GET /api/v1/users/projects`（`useProjects()` 経由。`limit` / `page` は指定せず、全件を使う）
- `Project` の項目: `name`, `slug`, `goal`, `shouldbe`, `deadline`, `color`, `stats.kinds.milestone`, `stats.kinds.task`

## デザイン・補足

- Figma のリンクはなし。添付のデザイン画像（ユーザーから受け取ったスクリーンショット）をもとにしている。
- レイアウト: 見出し「プロジェクト」は左上に小さく置く。その下に、中央寄せの幅 800px 前後の 1 列を作り、件数表示・カード・ページ送りを並べる。カードどうしの間隔は 16px 前後。
- カード: 白い面（`--color-surface`）に `--shadow-card` の影。左端に色付きの太い縦線（約 5px）。上段は左にプロジェクト名（小さく太字、プロジェクトの色）、右に期限日。中段にゴール（大きく太字）とあるべき姿（薄い文字）。下段右にマイルストーン数とタスク数（アイコン + 数）。
- 色・影は `src/_app/styles/globals.scss` の CSS 変数（`--color-surface`, `--color-text`, `--color-text-sub`, `--color-text-muted`, `--color-primary`, `--shadow-card` など）を使う。プロジェクトの色は、既存の `RecentProject` と同じく `--project-color` として渡す。
- ページ送りの現在のページ番号は `--color-primary` で強調する。
- ダッシュボードの `src/_pages/home/ui/RecentProject.tsx` と表示項目が近いが、レイアウトが違い、FSD 上ページ間の import もできないため、`src/_pages/projects/` に専用のカードを作る。
