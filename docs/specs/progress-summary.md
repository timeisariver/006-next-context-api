# 進捗サマリー

## 目的

ダッシュボードの「進捗サマリー」に、日ごとの完了タスク数と予定タスク数を Chart.js の棒グラフで表示し、直近の進捗を一目で確認できるようにする。

## 対象ページ

- `/`（ダッシュボード）

## 要件

### グラフ

- [ ] 「進捗サマリー」の見出しの下に、完了タスクと予定タスクを日ごとに表した積み上げ棒グラフを Chart.js で表示する。
- [ ] 横軸は日付（`M / DD` 形式、例: `7 / 17`）、縦軸はタスク数にする。
- [ ] 完了タスクは濃い緑、予定タスクは薄い緑で塗る（API が返す系列ごとの色は使わず、`globals.scss` の CSS 変数に合わせる）。
- [ ] グラフの上に、完了タスク・予定タスクの凡例（色の四角とラベル）を表示する。
- [ ] 凡例の右に、グラフが表す期間を `YYYY-MM-DD ~ YYYY-MM-DD` で表示する（データの最初の日と最後の日）。
- [ ] グラフの下にも Chart.js の凡例を表示する。
- [ ] データの取得中・失敗・データなしのときに、グラフの代わりにそれが分かる表示を出す。

### 集計カード

- [ ] グラフの下に「完了タスク」「予定タスク」「完了率」の 3 枚のカードを横に並べる。
- [ ] 「完了タスク」「予定タスク」カードには、期間内の合計数を大きく表示する。
- [ ] 「完了率」カードには、完了タスクの合計 ÷（完了タスクの合計 + 予定タスクの合計）を四捨五入した整数のパーセントで表示し、ドーナツグラフで表す（合計が 0 のときは 0%）。

### 期間

- [ ] 右上に期間の選択ボタンの見た目（枠付き、「週」と下向き矢印）を表示する。「週」のみで、押しても切り替わらない。
- [ ] 期間欄のカレンダーアイコンは飾りで、押しても何も起きない。
- [ ] 期間は API が返す日付をそのまま使う（今日の前後 3 日、計 7 日分）。

## 対象外

- 前週比（増減）の表示。API に前の期間のデータがなく、ダミー値も出さない。スクリーンショットの `+44%` と「前週比」は作らない。
- 「週」以外（日・月・年）の期間と、日付の選択。
- 期間の切り替えで API に問い合わせ直すこと（API が期間を受け付けないため）。
- グラフの棒をクリックしての詳細表示や、タスクの絞り込み。
- ダークモード対応。
- 他のダッシュボード部品（最近のプロジェクト、タスク一覧）の変更。
- `app/api/` の変更。

## 使う API・データ

- `GET /api/v1/users/stats`（仕様は `/api/v1/spec` を参照）。
  - レスポンスは `{ data: Stats[] }`。`Stats` は `{ label, type, data: { date, value }[] }` で、`type` は `completed`（完了タスク）と `todo`（予定タスク）の 2 系列。
  - `date` はミリ秒のタイムスタンプ、`value` はその日のタスク数。2 系列とも同じ日付が同じ順に並ぶ。
  - 現在のダミーデータは、今日の前後 3 日の計 7 日分で、値は起動のたびにランダム。
- Chart.js は `package.json` に `chart.js` が導入済み。
- API のレスポンス型は `src/shared/api/` に手書きする。

## デザイン・補足

- 参考画像（スクリーンショット）の構成:
  - 上段: 見出し「進捗サマリー」、右に期間の選択ボタン（枠付き、「週」と下向き矢印）。
  - 中段: 左に凡例、右に期間（カレンダーアイコン付きの日付 2 つを `~` でつなぐ）。その下に積み上げ棒グラフ。
  - 下段: 3 枚の集計カード。枠線付きの角丸で、ラベル（小さめ・太字）、数値（大きく細め）を並べる。増減と「前週比」は作らない。
- 色は `src/_app/styles/globals.scss` の CSS 変数に当たるものを使う。濃い緑は `--color-primary`、薄い緑は `--color-primary-bg` / `--color-primary-bg-strong` が近い。棒の緑（`#8fe3c7` 前後）と完了率ドーナツの灰色の地は、当たる変数がないので、既存の変数で代用できないか確認してから追加する。Chart.js は canvas に描くため CSS 変数を直接使えない。値は `getComputedStyle` で読むなどして、16 進数を直接書かない。
- 既存の `Summary`（`src/_pages/home/ui/Summary.tsx`）に組み込む。見出しは `DashboardHead` を使う。
- `app/api/datastore/models/stats.ts` に、API 側が想定するグラフの色（完了 `#8fe3c7`、予定 `#8fe3c740`）がある。参考にしてよい。
