# サイドバーの開閉

## 目的

サイドバーを閉じて、メインのコンテンツを広く使えるようにする。開いているときも閉じているときも、同じボタンで切り替えられる。

## 対象ページ

- 全ページ（サイドバーは共通レイアウトにあるため）。PR のスクリーンショットは `/` から撮る。

## 要件

- [ ] サイドバー上部の開閉ボタン（現在は `TODO: サイドバーの開閉は未実装` のまま動かない）を押すと、サイドバーが閉じる。
- [ ] 閉じた状態でも開閉ボタンは残り、押すとサイドバーが開く。
- [ ] 開いているときの開閉ボタンは左向きの矢印、閉じているときは右向きの矢印にする。
- [ ] 開閉ボタンの `aria-label` は、開いているときは「サイドバーを閉じる」、閉じているときは「サイドバーを開く」にする。
- [ ] 開閉に合わせて、サイドバーの幅がアニメーションで変わる（`Sidebar.module.scss` に幅の `transition` が既にある）。
- [ ] サイドバーが閉じると、メインのコンテンツがその分広がる。
- [ ] 閉じたときのサイドバーの幅は 47px にし、開閉ボタンだけが見える細い状態にする。
- [ ] 閉じている間は、メニュー項目（アイコンも文字も）とプロジェクト一覧は表示しない。
- [ ] 画面を最初に開いたときは、サイドバーは開いている。
- [ ] ページを移動しても、開閉の状態は保たれる（リロードすると開いた状態に戻る）。

## 対象外

- リロード後に開閉の状態を覚えておくこと（リロードすると開いた状態に戻る）。
- キーボードショートカットでの開閉。
- ドラッグでサイドバーの幅を変えること。
- ヘッダーなど、サイドバー以外の部分の変更。
- モバイル幅向けのドロワー表示。

## 使う API・データ

- なし（画面の状態のみ）。

## デザイン・補足

- 開閉ボタンは `src/_app/layouts/Sidebar.tsx` の `toggle`、サイドバーの幅と `transition` は `Sidebar.module.scss` の `.root` に既にある。
- アイコンは lucide-react の `ChevronLeft` / `ChevronRight` を使う想定。
- Figma のリンクはなし。
